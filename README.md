# Telegram-бот мероприятий бизнес-сообщества «Эквиум»

Бот информирования о мероприятиях. Подписчики общаются с ботом **только через кнопки**
русифицированного главного меню; администраторы управляют списком мероприятий и участниками.

## Возможности

### Подписчик (главное меню — инлайн-кнопки)
- **Об Эквиум** — ссылка на сайт сообщества (`ABOUT_URL`).
- **О мероприятиях** — отдельная кнопка-ссылка на каждое актуальное мероприятие.
- **Связаться с координатором** — номер телефона + кнопка «Написать сообщение»
  (ведёт в личку координатора `COORDINATOR_USERNAME`, либо копирует номер).
- **Стать участником сообщества** — готовая ссылка на Google-форму (`JOIN_FORM_URL`).

Подписаться можно самостоятельно по ссылке на бота (`/start`).

### Администратор (предустановленные аккаунты из `ADMIN_USER_IDS`)
- **Добавить мероприятие** (название → ссылка). Сразу после добавления всем подписчикам
  мгновенно рассылается уведомление 🔔; недоступные (заблокировавшие бота) удаляются из базы.
- **Удалить прошедшее / изменить мероприятие** в панели «Меню „О мероприятиях“»
  (удаление с подтверждением; редактирование в формате `название | ссылка`).
- **Добавить участника по номеру телефона**: админ вводит номер — когда человек напишет
  боту (сам или поделившись контактом), он автоматически зачисляется в подписчики.
- **Список участников** — счётчик подписчиков.
- Команды: `/events`, `/admin`, `/cancel`.

## Структура проекта

```
bot/
├── main.py          # логика бота (хендлеры команд, кнопок, диалоги админа, рассылка)
├── keyboards.py     # русифицированные клавиатуры (меню подписчика и администратора)
├── storage.py       # SQLite: subscribers, events, phone_invites
├── config.py        # конфигурация через переменные окружения
├── test_logic.py    # тесты логики без реального Telegram API
├── requirements.txt
└── .env.example     # пример конфигурации
```

## Установка и запуск

```bash
cd bot
pip install -r requirements.txt
cp .env.example .env      # заполните BOT_TOKEN, ADMIN_USER_IDS, ссылки и телефон
export $(grep -v '^#' .env | xargs)   # или используйте python-dotenv / systemd EnvironmentFile
python main.py
```

Тесты: `python test_logic.py`

## Масштаб

Расчёт на ~300 подписчиков: рассылка идёт последовательно через Bot API
(Telegram допускает ~20–30 сообщений/сек боту в среднем, для 300 адресов это ~15 секунд).
При росте базы можно добавить `asyncio.gather` пачками или JobQueue.

## Как получить ID администратора

Напишите боту @userinfobot — он вернёт ваш числовой `user id`; добавьте его в `ADMIN_USER_IDS`
через запятую.
